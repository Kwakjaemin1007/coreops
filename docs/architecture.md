
## 전체 구조

```text
┌───────────────────────────────────────────────────────────────────────────────┐
│ NRF : every NF registers here and looks up other NFs here                     │
└───────────────────────────────────────────────────────────────────────────────┘

[ Control Plane ]
                                        ┌──────┐
                                        │ NSSF │
                                        └──┬───┘
                                           │
┌────┐        ┌─────┐ N2 (SCTP 38412)   ┌──┴───┐        ┌──────┐        ┌───────┐
│ UE │◀──────▶│ gNB │──────────────────▶│ AMF  │───────▶│ AUSF │───────▶│UDM/UDR│
└────┘        └──┬──┘                   └──┬───┘        └──────┘        └───────┘
                 │                         │
                 │                         ▼
                 │                      ┌──────┐        ┌──────┐
                 │                      │ SMF  │◀───────│ PCF  │
                 │                      └──┬───┘        └──────┘
                 │                         │ N4 (UDP 8805)
                 │                         │
=================│=========================│=====================================
[ User Plane ]   │ N3 (UDP 2152)           ▼
                 │                      ┌──────┐            ┌────────┐
                 └─────────────────────▶│ UPF  │────TUN────▶│Internet│
                                        └──────┘            └────────┘
```

- UE는 gNB에만 무선으로 연결된다. UE의 등록 요청(NAS)은 gNB를 거쳐 AMF로 전달된다.
- NSSF는 AMF에, PCF는 SMF에 연결되고, 모든 NF는 NRF에 등록하고 조회한다.

## 등록부터 데이터 통신까지

1. 등록: UE → gNB → AMF에 접속 요청
2. 인증: AMF → AUSF → UDM/UDR에서 가입자 정보 확인
3. 등록 완료: AMF가 UE에게 승인
4. 세션 요청: UE의 요청을 AMF가 SMF에 전달
5. 세션 생성: SMF가 PCF에서 정책을 받고, N4로 UPF에게 통로 설정을 지시
6. 개통: gNB와 UPF 사이에 N3 터널이 열리고 데이터가 오간다
